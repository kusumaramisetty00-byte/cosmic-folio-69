# Nexus Port

Build a Single-Page Portfolio Website — Pure HTML, CSS & JavaScript

Build a premium, futuristic, dark-themed personal portfolio website as a single-page website.

CRITICAL TECHNOLOGY REQUIREMENT

Use ONLY:

HTML5

CSS3

Vanilla JavaScript

Do NOT use:

React

Next.js

Vue

Angular

Svelte

Bootstrap

Tailwind CSS

jQuery

TypeScript

Any CSS framework

Any JavaScript framework

Any UI component library

The website must work as a traditional static website using:

index.html

style.css

script.js

Keep the code clean, readable, modular, and easy for a beginner to understand and edit.

WEBSITE TYPE

Create a single-page portfolio website.

All sections must exist on the same page.

Navigation links should smoothly scroll to sections instead of opening separate pages.

Use section IDs such as:

#home

#about

#skills

#projects

#experience

#education

#certifications

#achievements

#blog

#resume

#contact

Do NOT create separate HTML pages for these sections.

1. DESIGN STYLE

The overall design should be:

Dark + Classy + Futuristic + Professional

The website should look like a premium modern technology portfolio rather than a generic student portfolio.

Visual direction

Use:

Deep black/dark charcoal background

Subtle futuristic gradients

Elegant white/light-gray typography

Subtle cyan/blue/purple accent colors

Glassmorphism where appropriate

Thin glowing borders

Soft shadows

Modern cards

Subtle background grid

Very subtle futuristic decorative elements

Do not make the website excessively neon.

The final design should feel:

Premium, sophisticated, futuristic and recruiter-friendly.
